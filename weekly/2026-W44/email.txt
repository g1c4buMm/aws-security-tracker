PHP2Shell foi explorado antes da divulgação e já tem mitigação no AWS WAF: atualize os servidores PHP expostos esta semana e confira a nova CVE-2026-115560.

DESTAQUES DA SEMANA

1. [Alta] [BLOG] Using AWS WAF to apply mitigations for PHP2Shell RCE vulnerabilities (CVE-2026-109618 and CVE-2026-109619) (2026-10-22)
https://aws.amazon.com/blogs/security/using-aws-waf-to-apply-mitigations-for-php2shell-rce-vulnerabilities-cve-2026-109618-and-cve-2026-109619/
Por que importa: A regra PHP2Shell_BODY do grupo gerenciado de aplicações PHP do AWS WAF, versão 2.4 ou superior, já bloqueia requisições POST usadas no ataque. O PHP divulgou também a CVE-2026-115560, outra RCE que as versões de 21 de outubro não corrigem. Ela afeta só aplicações com session upload progress ativado.
Ação sugerida: Confirme que os web ACLs das aplicações PHP usam o grupo de regras na versão 2.4 ou superior e verifique se o session upload progress está ativado.

2. [Alta] [BLOG] Amazon Threat Intelligence identifies PHP2Shell exploitation prior to public disclosure in MadPot (2026-10-21)
https://aws.amazon.com/blogs/security/amazon-threat-intelligence-identifies-php2shell-exploitation-prior-to-public-disclosure-in-madpot/
Por que importa: A Amazon Threat Intelligence viu exploração do PHP2Shell no MadPot quatro dias antes da divulgação pública. O ataque já circula, então a janela para corrigir é curta.
Ação sugerida: Busque nos logs sinais de exploração do PHP2Shell e priorize a atualização dos servidores PHP expostos.

3. [Média] [NOVIDADE] AWS Continuum for code vulnerabilities is now generally available (2026-10-22)
https://aws.amazon.com/about-aws/whats-new/2026/10/aws-continuum-for-code-vulnerabilities-is-now-generally-available
Por que importa: O AWS Continuum for code vulnerabilities chegou ao GA para descobrir, validar, priorizar e corrigir vulnerabilidades de código. Usa topologia, identidade e alcance de rede para medir o risco real e confirma com testes o que é explorável.
Ação sugerida: Avalie um piloto do AWS Continuum em uma aplicação crítica.

4. [Média] [NOVIDADE] Amazon GuardDuty adds optional threat detection rules for Runtime Monitoring (2026-10-19)
https://aws.amazon.com/about-aws/whats-new/2026/10/guardduty-runtime-optional-detection-rules/
Por que importa: O Amazon GuardDuty Runtime Monitoring ganhou regras opcionais de detecção para EC2, EKS e ECS, mapeadas ao MITRE ATT&CK. Elas cobrem casos como alteração do sudoers e desativação de logs de auditoria.
Ação sugerida: Revise as regras opcionais e ative primeiro as de persistência e evasão de defesa.

5. [Média] [NOVIDADE] AWS Network Firewall now supports Route 53 Resolved IP Validation (2026-10-21)
https://aws.amazon.com/about-aws/whats-new/2026/10/network-firewall-route-53-ip-validation/
Por que importa: O AWS Network Firewall agora valida se o IP de destino veio do Route 53 VPC Resolver da sua VPC. Isso fecha o desvio das regras de domínio e estende a filtragem a SSH e SFTP.
Ação sugerida: Avalie ativar a validação de IP nas regras de domínio para tráfego de saída SSH e SFTP.

6. [Média] [NOVIDADE] AWS IAM Identity Center simplifies identity source changes from Active Directory (2026-10-20)
https://aws.amazon.com/about-aws/whats-new/2026/10/iam-identity-center-chg-id-src-from-ad/
Por que importa: O IAM Identity Center agora preserva usuários, grupos e atribuições ao trocar a fonte de identidade de Active Directory para um IdP externo. Isso reduz o risco de perda de acesso ou de permissões erradas na migração.
Ação sugerida: Se a sua fonte ainda é Active Directory, revise o plano de migração e valide as atribuições após a troca.

7. [Média] [BLOG] Updating encryption on existing Amazon S3 objects with S3 Batch Operations (2026-10-21)
https://aws.amazon.com/blogs/storage/updating-encryption-on-existing-amazon-s3-objects-with-s3-batch-operations/
Por que importa: A nova API UpdateObjectEncryption com S3 Batch Operations migra objetos de SSE-S3 para SSE-KMS no lugar. Não é preciso mover dados, e as políticas de S3 Lifecycle continuam funcionando.
Ação sugerida: Liste os buckets que ainda usam SSE-S3 e planeje a migração para SSE-KMS.
